# 11ty Start Bootstrap Creative

A faithful Eleventy conversion of the Start Bootstrap Creative theme.

The original HTML, CSS, JavaScript, and image paths are preserved as closely as possible. Eleventy is used only to build the static page and supporting metadata files.

## Commands

```sh
npm install
npm run build
npm run dev
```

## Project Structure

- `src/index.html` is the original Creative page.
- `src/css/styles.css` is the bundled Start Bootstrap and theme CSS.
- `src/js/scripts.js` is the original theme JavaScript.
- `src/assets/` contains the favicon and image assets.
- `_site/` is the generated Eleventy output.

## Generated Files

The Eleventy build also creates:

- `sitemap.xml`
- `feed.xml`
- `robots.txt`
- `humans.txt`
